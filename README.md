# Vendora

AI SDR SaaS for Brazilian B2B SMBs. See `docs/superpowers/specs/` for design.

## Local development

1. Copy `.env.example` to `.env.local` and fill values from Supabase dashboard.
2. `pnpm install`
3. `pnpm dev`
4. Open http://localhost:3000

## Stack

Next.js 16, TypeScript, Tailwind v4, shadcn/ui, Supabase (Auth + Postgres), Inngest, Google Gemini, Lemon Squeezy.
